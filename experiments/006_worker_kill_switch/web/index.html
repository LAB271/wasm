Experiment 006 — Worker.terminate() as a kill switch

Query param ?variant=pure|alloc. Starts a genuinely unconditional WASM loop in a Worker (no exit condition, no cooperative check). The loop ticks a SharedArrayBuffer heartbeat counter every N iterations — observability only, not a control mechanism. window.terminateWorker() and window.readHeartbeat() are exposed for the benchmark harness.
