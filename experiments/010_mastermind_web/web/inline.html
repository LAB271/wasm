FETCHvsINLINE

Loads engine-rust.wasm two ways — a plain fetch() of the binary, and a base64 string inlined into an ES module (engine-*.b64.js) — and measures both. Switch engine with ?engine=rust|as.

Request count and bytes transferred are the numbers that generalize to a real network. Timings here are localhost — RTT ≈ 0, so any speedup shown is noise, not a real-network result. See README for the honest read.
